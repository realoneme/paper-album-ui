# Typography

The reading styles: headings in Fraunces with one italic phrase, body in Instrument Sans, quotes with a wood rule, inline code on a muted chip.

- React: `TypographyH1`–`TypographyH4`, `TypographyLead`, `TypographyP`, `TypographyBlockquote`, `TypographyInlineCode`, `TypographyList`, `TypographyMuted`, `TypographyNote` (handwritten). `pa-display` and `pa-label-caps` stay as classes.

```tsx
<TypographyH1>The year we followed <em>the snow</em></TypographyH1>
<TypographyLead>Two weeks in Hokkaido, four rolls a day.</TypographyLead>
<TypographyBlockquote>“Photograph the cold the way it feels.”</TypographyBlockquote>
<TypographyNote>Lisbon, early light</TypographyNote>
```
