# Select

A custom listbox for short option lists with groups; the trigger is a paper key, the list a top sheet.

- Props: `value`, groups of options, disabled options.
- Classes: `pa-trigger`, `pa-pop pa-menu`, `pa-grp`, `pa-mi` (`.on` for the selected option), `pa-sep`.
- Build on shadcn Select (Radix) for keyboard and positioning.
