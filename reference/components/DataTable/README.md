# Data Table

Table plus tools: filter, column menu, sortable headers, row selection, row actions and pagination.

- Consumer provides: columns, rows, sort state, selection, page.
- Classes: `pa-table` with `pa-check` in the first column, `aria-sort` on sortable headers, `tr[aria-selected="true"]` for selected rows.
- Build on shadcn Data Table (TanStack Table).
