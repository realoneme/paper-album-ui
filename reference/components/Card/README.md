# Card

A raised sheet with header, content and footer; use `stack` for album cards that show page thickness.

- Consumer provides: optional media, title, description, actions.
- Classes: `pa-card` (+ `.stack`), `pa-card-header`, `pa-card-title`, `pa-card-desc`, `pa-card-content`, `pa-card-footer`.
- Footer actions use `pa-btn-sm` buttons, so a card's actions stay lighter than the page's own.
