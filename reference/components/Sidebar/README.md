# Sidebar

The studio app shell: a sidebar of grouped links with counts and a nested group, beside the content area.

- Consumer provides: brand, groups of links, the current page, a user footer.
- Classes: `pa-shell`, `pa-sidebar` (`.brand`, `.mark`, `.grp`, links with `aria-current="page"`), content area of your own.
- Uses the `sidebar-*` tokens; build on shadcn Sidebar for collapse and mobile.
